# Claude Code

Setup for this repository is in [AGENTS.md](AGENTS.md). Read that file and follow it.

It covers the one-line Grok Bot setup. After the routine exists, Grok Bot sends one message: install the extension, then paste the Webhook URL and Authorization header together at sendtogrokbot.com/connect. The Claude clicks were checked on screen: Scheduled in the left sidebar, New task, Set up manually, paste the task prompt, Trigger set to API, Create. Claude shows the API token once; the Fire URL is the copy button next to API on the task page. No allowed domains are needed. Secrets go on the connect page or the extension options page, not into the chat.
