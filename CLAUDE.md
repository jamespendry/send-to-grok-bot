# Claude Code

Setup for this repository is in [AGENTS.md](AGENTS.md). Read that file and follow it.

If you are any Claude, follow the **Claude Code** section of AGENTS.md. It picks a path from your tools: with Claude in Chrome you create the Send to Claude task and connect the extension yourself, and without browser tools you walk the person through sendtogrokbot.com/setup/claude one step at a time.

If the extension is not installed, send the person to https://sendtogrokbot.com/install and wait. You cannot install it for them. Chrome blocks extensions and agents from chrome:// pages and the Web Store.

Never let the API token enter your context or the chat. Use the script in that section to move it from claude.ai to the connect page.
