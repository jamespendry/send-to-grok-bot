# Claude Code

Setup for this repository is in [AGENTS.md](AGENTS.md). Read that file and follow it.

It covers the one-line Grok Bot setup. After the routine exists, Grok Bot sends one message: install the extension, then paste the Webhook URL and Authorization header together at sendtogrokbot.com/connect. The Claude clicks were checked on screen: left sidebar Routines, the three dots next to Active, Edit, Trigger set to API, then Allowed domains on a past run under Edit cloud environment. Secrets go on the connect page or the extension options page, not into the chat.
