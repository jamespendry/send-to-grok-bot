Set up on iPhone

Share any post from the X app to your AI. One tap to install. Nothing to set up.

  1. Install Send to Grok Bot

    Open this page on your iPhone and tap Install Send to Grok Bot. When Shortcuts opens, tap Add Shortcut.

    If your browser downloads a file instead of opening Shortcuts, open this page in Safari and tap Install again.

    Installed an older version? Delete it in the Shortcuts app first, so you don't end up with "Send to Grok Bot (1)".

  2. Share a post

    In the X app, tap the share arrow under any post. Then:

  3. Put it at the top of the list

    Do this once, so you never scroll for it again.

    1. Open the share list the same way: share arrow, then Share via…
    2. Scroll to the very bottom and tap Edit Actions (circled in orange above).
    3. Find Send to Grok Bot and tap the green plus next to it. Tap Done.

    It now sits in Favorites, near the top of the list, every time you share.

  4. Read the reply

    Claude and ChatGPT open with the post already filled in. If the message waits, press Send.

    For Grok Bot, the message is copied for you and Grok Bot opens. Tap the message box, tap Paste, and send.

Codex works from the Chrome extension. On iPhone it only opens the website, so it is not in the menu.

The Shortcut sends the post link to sendtogrokbot.com to look up the post's text, then hands it to the app you picked. Nothing is saved. Privacy
