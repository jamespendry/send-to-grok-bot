Send to Grok Bot

    Set up on iPhone

    Share any post from the X app to your AI. Do this once, here on your iPhone.

    Use Safari for setup. Chrome and Firefox on iPhone can't always open Shortcuts. Copy this page's address and open it in Safari.

    Grok Bot Stays in XGrok Bot sets itself up and replies in the background. You copy two things. Claude Nothing to connectClaude opens with the post filled in. You tap Send. ChatGPT Nothing to connectChatGPT opens with the post filled in. You tap Send.

    On a computer? Set up the Chrome extension. Codex works there; on iPhone it only opens the website, so it isn't offered here.

    Choose AI

    Connect Grok Bot

    Grok Bot sets itself up. You send it one line, then copy two things back here.

    1. Send Grok Bot this line

      Set up Send to Grok Bot on my iPhone: https://github.com/jamespendry/send-to-grok-bot
      Open Grok Bot

      Paste it into any Grok Bot chat. If it asks you to confirm, confirm. Already have the routine, for example from the Chrome extension? Skip to step 3.

    2. Wait for "routine is ready"

      Grok Bot creates a routine named Send to Grok Bot, then replies that it's ready and tells you to switch back here.

      Grok Bot didn't make it?

      Send this simpler line instead, then continue.

      Create a routine named Send to Grok Bot with a webhook trigger.

    3. Copy the URL and Header here

      In Grok Bot, tap Grok Bot at the top of the chat, then Routines, then Send to Grok Bot. Scroll to Webhook.

      1. Tap the URL row to copy it. Switch back to this page, tap the box, then tap Paste.
      2. Switch back to Grok Bot, tap the Header row, and paste it here the same way.

      Either order works. It connects as soon as both are pasted.

      Keep this routine. The URL and Header belong to it. If you delete it and make a new one, they change and your shares stop arriving. If that happens, paste the new URL and Header here again.

    Choose AI

    Add the Shortcut

    The Shortcut puts Send to Grok Bot in your share sheet and sends posts in the background.

    The Shortcut puts Send to Grok Bot in your share sheet and opens Claude with the post filled in.

    1. Install it

      Install Send to Grok Bot

      Shortcuts opens. Tap Add Shortcut, then switch back to this page.

      Shortcuts didn't open, or you have an older version?

      Delete any older Send to Grok Bot in the Shortcuts app first, so the new one isn't named "Send to Grok Bot (1)". If Shortcuts doesn't open, download the file instead and open it from your browser's Downloads.

    2. Tap Finish to send a test

      Shortcuts opens and sends Grok Bot a test. The first time, iPhone asks a few questions. Tap Open or Allow. When you see Always Allow, tap that, not Allow Once, or iPhone asks again on every share.

      Finish turns on once Grok Bot is connected. Connect Grok Bot

    3. Turn on Grok Bot's notifications

      You land in Grok Bot, where it answers the test. Tap Grok Bot at the top of the chat, then turn on Notifications, so you know when a reply is ready.

    4. Sign in to the Claude app

      Have the Claude app installed and signed in. That's all.

    Next: Try it
    Add the Shortcut

    Try it

    Open the X app and tap the share arrow under any post.

    That's it. A Sent to Grok Bot notice appears and you stay in X. When the reply is ready, Grok Bot sends you a notification. Tap it to read the reply.
    That's it. Claude opens with the post and its thread filled in. Tap Send.

    Put it at the top of the share list

    1. Open the share list the same way: share arrow, then Share via…

    2. Scroll to the very bottom and tap Edit Actions.

    3. Find Send to Grok Bot, tap the green plus next to it, then tap Done.

    With Grok Bot connected, the Shortcut always sends to Grok Bot. Without it, the Shortcut asks which AI each time.

    Start over with a new code

    Use this if your code was shown on screen, for example in a screen recording. The old code stops working, and you paste the URL and Header again.

    The Shortcut sends the post link to sendtogrokbot.com to look up the post's text. For Grok Bot, the relay passes the post to your webhook; your webhook key is stored encrypted on the relay, which keeps a short list of recent sends (the link and author, not the text). Privacy
