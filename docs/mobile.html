Send to Grok Bot on iPhone

Tap one link. Paste one code. Then share a post from the X app.

1. Copy the code

  1. On a computer, open relay.sendtogrokbot.com.
  2. Copy the code. It starts with stgbr1. This is the only code. Do not copy a webhook address.
  3. If you want Grok Bot or Claude, save that destination on the same page. ChatGPT and Codex need nothing saved.

2. Add the shortcut

Install Send to Grok Bot

  1. On the iPhone, tap Install Send to Grok Bot.
  2. Tap the downloaded file, then tap Add Shortcut.
  3. When Shortcuts asks, paste the code. Paste it once.

If iOS says the shortcut is untrusted, open Settings, tap Shortcuts, and turn on Allow Untrusted Shortcuts. Tap the link again. If Settings has no such switch, open the downloaded file from the Files app and tap Add Shortcut.

3. Send a post

  1. In the X app, open a post and tap Share.
  2. Tap Send to Grok Bot.
  3. Pick Grok Bot, Claude, ChatGPT, or Codex.

A notification names the destination. ChatGPT and Codex then open with the post filled in. You press Send in that app. Grok Bot and Claude are sent for you, using what you saved on the relay.

If Share does not list the shortcut, tap More on the share sheet and turn on Send to Grok Bot.

The last 50 sends are on History. Paste the same code there. That page does not save the code.

Build it yourself

Use this only when the install link above is still missing. In the Shortcuts app, create a shortcut named Send to Grok Bot, turn on Show in Share Sheet, and add these actions in order.

  1. Text. Paste the relay code. This stays the first action.
  2. Set Variable named Relay Code.
  3. Get URLs from Input. Input is Shortcut Input. Then Set Variable named Links.
  4. If Links has any value.
  5. Inside that If: Get Item from List, First Item, from Links. Set Variable named Post URL.
  6. Choose from Menu. The lines are Grok Bot, Claude, ChatGPT, and Codex.
  7. Under each line, add Text with exactly grokbot, claude, chatgpt, or codex, then Set Variable named Destination.
  8. Below End Menu, add Get Contents of URL. URL https://relay.sendtogrokbot.com/v1/send. Method POST. Header Authorization is Bearer plus the Relay Code variable. Header Content-Type is application/json. JSON body: destination is Destination, url is Post URL, source is shortcut.
  9. Get Dictionary from Input, then Set Variable named Response.
  10. Get Dictionary Value for notice, from Response. Set Variable named Notice.
  11. Get Dictionary Value for openUrl, from Response. Set Variable named Open URL.
  12. Show Notification. Title Send to Grok Bot. Body is Notice.
  13. If Open URL has any value, Open URLs with Open URL.
  14. In the Otherwise of the first If, show a notification: No post link was shared.
