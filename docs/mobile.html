Send to Grok Bot
Get started

On iPhone

Share any post from the X app to your AI. One tap to install. Nothing to set up.

  1. Install

    Install Send to Grok Bot

    Open this page on your iPhone and tap Install Send to Grok Bot. When Shortcuts opens, tap Add Shortcut.

    Installed an older version? Delete it in the Shortcuts app first, so you don't end up with "Send to Grok Bot (1)".

  2. Share a post

    In the X app, tap Share on any post, then Send to Grok Bot. Pick Grok Bot, Claude, ChatGPT, or Codex.

    Don't see it? Scroll to the bottom of the share list, tap Edit Actions, and add Send to Grok Bot.

  3. Press Send

    Claude, ChatGPT, and Codex open with the post and its thread already filled in. Read it over and press Send.

    For Grok Bot, the message is copied for you. Grok Bot opens. Paste it into the chat and send.

The Shortcut sends the post link to sendtogrokbot.com to look up the post's text, then hands it to the app you picked. Nothing is saved. Privacy
