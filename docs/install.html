Setup

Install the extension

Do this once, on a computer, in Chrome. It takes about two minutes. Every AI needs it first, and no AI can do it for you, because Chrome doesn't let anything but you add extensions.

It isn't in the Chrome Web Store yet, so it takes a few extra clicks. When it's in the store, this page becomes one Add to Chrome button.

  1. Download it

    Download the extension

  2. Unzip it

    Open your Downloads folder and double-click send-to-grok-bot.zip. You get a folder named send-to-grok-bot. On Windows, right-click the zip and choose Extract All.

  3. Open Chrome's extensions page

    Copy this, paste it into Chrome's address bar, and press Enter. Websites can't link to it directly.

    chrome://extensions

  4. Turn on Developer mode, then click Load unpacked

    Switch on 1 Developer mode at the top right. Then click 2 Load unpacked and choose the send-to-grok-bot folder from step 2.

  5. Pin it (optional)

    Click the puzzle-piece icon next to Chrome's address bar, then the pin next to Send to Grok Bot. Its icon opens the settings.
