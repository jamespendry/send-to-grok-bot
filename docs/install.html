Install the extension

It's installed.You can skip this step.
Next: Choose your AI

On a computer, in Chrome. You do this once.

  1. Download the extension

  2. Unzip it

    Open your Downloads folder and double-click send-to-grok-bot.zip. You get a folder called send-to-grok-bot. Leave it there.

    On Windows: right-click the zip, then Extract All.

  3. Open Chrome's extensions page

    Copy this, paste it into the address bar at the top of Chrome, and press Enter.

    chrome://extensions

  4. Turn on Developer mode, then click Load unpacked

    Switch on Developer mode at the top right of the page.

    Three buttons appear at the top left. Click Load unpacked, then choose the send-to-grok-bot folder in your Downloads and click Select.

    Pick the folder itself, not a file inside it. If it says "Manifest file is missing", you picked the folder one level up: open it and choose the send-to-grok-bot folder inside.

    Can't switch on Developer mode? Chrome from work or school can lock it. Use your personal Chrome instead.

  5. Pin it, then come back here and refresh

    Click the puzzle-piece icon at the top right of Chrome, then the pin next to Send to Grok Bot, so its icon stays in view. Then refresh this page. It checks for the extension and moves you to the next step.
