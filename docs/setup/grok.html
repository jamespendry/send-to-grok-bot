Grok Bot

Grok Bot creates the routine. It cannot read the webhook key, so it does not hand you a link. You copy two sidebar values and paste them once. You do not paste a key into a chat.

1. Send this line

Paste it into the Grok Bot you want to use:

Set up Send to Grok Bot for me: https://github.com/jamespendry/send-to-grok-bot

The bot reads the project, creates a webhook routine named Send to Grok Bot, and puts the General prompt on that routine. General classifies each post and starts with a one-line takeaway. If it asks you to confirm the routine, confirm it.

2. Follow the one message it sends

After the routine exists, the bot sends one message. It tells you how to install the extension, then this:

Open the sidebar links named Webhook URL and Authorization header, copy both, and paste them together at sendtogrokbot.com/connect.

Open the connect page. Step 1 is the install. Step 2 is the box. Paste both values together. If the extension is installed, that paste saves them. If Chrome asks to allow a site, choose Allow. The page then says: Now open x.com and click the arrow.

On x.com, click the arrow on a post and choose Send to Grok Bot. The icon turns green when the run has started. The reply shows up in the bot's chat when the run finishes.

Where those two values are

Do this on a computer, in Grok Bot. The phone app does not show these fields. The sidebar links are named Webhook URL and Authorization header.

  1. Open the bot's sidebar.
  2. Open the Routines tab.
  3. Open the routine named Send to Grok Bot.
  4. At the bottom, When to run is Webhook and Method is POST. Copy the URL and the Authorization header.
  5. Open the connect page and paste both together.

You can also paste both into the box at the top of the extension's settings page. The word Bearer is removed for you. If Chrome asks, choose Allow.

Changing the reply later

Leave the routine prompt as General. On the extension settings page, under Replies, pick Research, Job hunt, Buy or skip, Learn later, or Content ideas. That choice is sent with the next post, and the routine follows it.
