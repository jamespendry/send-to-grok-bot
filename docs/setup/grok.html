Setup Grok Bot Claude Connect Privacy

Grok Bot

Grok Bot can create the routine and hand you one link. You click Connect. You do not copy a key into a chat.

1. Send this line

Paste it into the Grok Bot you want to use:

Set up Send to Grok Bot for me: https://github.com/jamespendry/send-to-grok-bot

The bot reads the project, creates a webhook routine named Send to Grok Bot, and puts the General prompt on that routine. General classifies each post and starts with a one-line takeaway.

2. Open the link it sends back

The reply should be one link, shaped like this:

https://sendtogrokbot.com/connect#stgb1.…

Open it. The box is already filled. Click Connect. If Chrome asks to allow a site, choose Allow.

That saves the routine's address and secret in the extension on this computer. Open x.com, refresh, and click the arrow on a post. Choose Send to Grok Bot. The icon turns green when the run has started. The reply shows up in the bot's chat when the run finishes.

If the bot cannot see the address

Do this on a computer, in Grok Bot. The phone app does not show these fields.

  1. Open the bot's sidebar.
  2. Open the Routines tab.
  3. Open the routine named Send to Grok Bot.
  4. At the bottom, When to run is Webhook and Method is POST. Copy the URL and the Authorization header.
  5. Open the connect page and paste both, in any order. Click Connect.

You can also paste the URL into Webhook URL on the extension's settings page, and paste the Authorization header into Webhook key. The word Bearer is removed for you. Click Save. If Chrome asks, choose Allow.

Changing the reply later

Leave the routine prompt as General. On the extension settings page, under Replies, pick Research, Job hunt, Buy or skip, Learn later, or Content ideas. That choice is sent with the next post, and the routine follows it.
