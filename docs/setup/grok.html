Setup

Grok Bot

The easiest setup. Grok Bot does the work. You paste one line and click one link.

Before you start: add the extension to Chrome. Add to Chrome

  1. Copy this line into Grok Bot

    Set up Send to Grok Bot for me: https://github.com/jamespendry/send-to-grok-bot

    Paste it into the Grok Bot you want to use. It reads the project, creates a webhook routine named Send to Grok Bot, and puts the General reply style on it. You never copy a key into a chat.

  2. Click the link it sends back

    The reply is one link shaped like https://sendtogrokbot.com/connect#stgb1.… The box on that page is already filled. Open it in Chrome, then click Connect. If Chrome asks to allow a site, choose Allow.

  3. You're done

    Open x.com and refresh. Click the Send button on any post and choose Send to Grok Bot. The icon turns green when the run has started. The reply shows up in your Grok Bot chat when the run finishes.

If the bot can't send a link

Do this on a computer. The phone app doesn't show these fields.

  1. In Grok Bot, open the bot's sidebar and go to the Routines tab.
  2. Open the routine named Send to Grok Bot.
  3. At the bottom, When to run is Webhook and Method is POST. Copy the URL and the Authorization header.
  4. Open the connect page, paste both into the box in any order, and click Connect.

Or paste them into the extension settings: the URL into Webhook URL and the header into Webhook key. The word Bearer is removed for you. Click Save. If Chrome asks, choose Allow.

Change the reply style later

Leave the routine as it is. In the extension settings, under Replies, pick Research, Job hunt, Buy or skip, Learn later, or Content ideas. The routine follows it on the next post.
