Grok Bot

Grok Bot creates the routine for you. You paste one line into Grok Bot, then paste two values on the connect page.

Before you start: add the extension to Chrome. Add to Chrome

  1. Copy this line into Grok Bot

    Set up Send to Grok Bot for me: https://github.com/jamespendry/send-to-grok-bot

    Grok Bot reads the project and creates a routine named Send to Grok Bot with the General reply style. If it asks you to confirm the routine, confirm it.

  2. Follow the one message it sends

    Grok Bot can't read the webhook key itself, so it sends one message: install the extension, then copy two values from its sidebar, Webhook URL and Authorization header. Do this on a computer. The phone app doesn't show them.

  3. Paste both on the connect page

    Paste both values together in the box. Pasting saves them. If Chrome asks to allow a site, choose Allow. The page then says: Now open x.com and click the arrow.

    Open the connect page

  4. You're done

    On x.com, click the arrow on a post and choose Send to Grok Bot. The icon turns green when the run starts, and the reply shows up in your Grok Bot chat when it finishes.

Can't find the two values?
  1. In Grok Bot on a computer, open the bot's sidebar and go to the Routines tab.
  2. Open the routine named Send to Grok Bot.
  3. At the bottom, When to run is Webhook and Method is POST. Copy the URL and the Authorization header.
  4. Paste both together on the connect page, or into the box at the top of the extension's settings. The word Bearer is removed for you.

Change the reply style later

Leave the routine as it is. In the extension settings, under Replies, pick Research, Job hunt, Buy or skip, Learn later, or Content ideas. The routine follows it on the next post.
