Setup

ChatGPT

Nothing to set up. Check one box and posts open in ChatGPT, ready to send.

  1. Check the box

    Click the Send to Grok Bot icon in Chrome's toolbar to open its settings. Check Send to ChatGPT and click Save.

  2. Send a post

    On x.com, click the Send button on any post and choose Send to ChatGPT. ChatGPT opens in a new tab with the post and your reply style already filled in.

  3. Press Send

    Read it over if you like, then press Send in ChatGPT. Make sure you're signed in to ChatGPT in this browser.

Have a ChatGPT workspace agent?

On Business or Enterprise, you can have posts run on an agent instead of opening a tab. In the extension, under Send to ChatGPT, open Workspace agent, if you already have one and paste the API trigger ID and access token. Most people can skip this.
