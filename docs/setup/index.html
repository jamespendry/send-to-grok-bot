Set up Send to Grok Bot

Send to Grok Bot adds one button on an X post. You click it and pick where the post should go. It is free. There is nothing to buy and no account to create for the extension.

Have a Grok Bot do the Grok setup

Paste this one line into Grok Bot:

Set up Send to Grok Bot for me: https://github.com/jamespendry/send-to-grok-bot

It creates the routine and replies with one link. Open that link and click Connect. The steps are on the Grok Bot page.

Pick where posts go

  • Grok Bot runs a routine for you after one connect link. If the bot cannot see the address, there is a short copy-and-paste fallback.
  • Claude can open a tab with no setup, or run a task. The task cannot be created for you. The page has the clicks, in order.
  • ChatGPT needs no setup. In the extension, check Send to ChatGPT and click Save. Clicking a post opens ChatGPT with the post filled in. You press Send.
  • Codex needs no setup. Check Send to Codex and click Save. Clicking a post opens Codex with the post filled in. You press Send.

How replies are written

Every send starts with a one-line takeaway. The default, General, classifies the post first:

  • Tool, repo, or app: what it does, whether it is worth installing, and how to try it.
  • Thread or long article: a 3-line summary, then the key takeaway.
  • News: what happened, why it matters, and what to watch.
  • Video: a description from the captions, thumbnail, and text. It does not claim to have watched.
  • Tip, prompt, or how-to: one step you can save.
  • Job, company, or founder: who they are, the stage, and who to follow.
  • Product or deal: worth buying or not.
  • Meme, opinion, or anything else: one line of context, then it stops.

On the extension's settings page, under Replies, you can switch the preset or edit the text. The choices are General, Research, Job hunt, Buy or skip, Learn later, and Content ideas. The one you pick is sent with the post.

On an iPhone

Share a post from the X app and pick Grok Bot, Claude, ChatGPT, or Codex. The steps are on the Mobile page. You paste one relay code. You do not copy a webhook address. Recent sends are on History.

Install the extension

Until it is in the Chrome Web Store, install it from the project folder. Open the repository README and follow the numbered install steps. Developer mode has to be on, and you select the folder named extension.
