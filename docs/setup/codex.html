Setup

Codex

Nothing to set up. Check one box and posts open as a Codex task, ready to send.

  1. Install the extension

    Skip this if you already did.

    Install steps

  2. Check the box

    Click the Send to Grok Bot icon in Chrome's toolbar to open its settings. Check Send to Codex and click Save.

  3. Send a post

    On x.com, click the Send button on any post and choose Send to Codex. Codex opens a new task with the post and your reply style already filled in. It works well for tools, repos, and how-tos.

  4. Press Send

    Read it over if you like, then press Send in Codex. Make sure you're signed in to Codex in this browser.

Use a specific environment

Optional. In the extension, under Send to Codex, open Environment and branch, if you already have them and fill them in. Leave them blank and Codex still opens.
