Connect

Step 1. Install the extension

Installed.

It is not in the Chrome Web Store yet.

  1. Download the zip from github.com/jamespendry/send-to-grok-bot.
  2. Unzip it. Find the folder named extension. That folder contains manifest.json.
  3. In the address bar, type chrome://extensions and press Enter.
  4. Turn on Developer mode.
  5. Click Load unpacked and select the extension folder.
  6. Come back to this page.

Step 2. Paste here

Open the sidebar links named Webhook URL and Authorization header. Copy both. Paste them in this box, together.

This page stays in your browser. Pasting saves into the extension on this computer. It does not upload the address or the header.

If Chrome asks to allow a site, choose Allow. Then open x.com and click the arrow on a post.

ChatGPT and Codex need none of this. Check the box in the extension and click Save. A post opens with the text filled in, and you press Send.
