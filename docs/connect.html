Two steps. Install the extension, then paste what your setup page told you to copy.

  1. Step 1. Install the extension

    Installed. Go to step 2.

    It is not in the Chrome Web Store yet, so it takes five short steps:

    1. Download the zip from GitHub and unzip it.
    2. In Chrome's address bar, type chrome://extensions and press Enter.
    3. Turn on Developer mode, at the top right.
    4. Click Load unpacked and pick the folder named extension.
    5. Come back to this page and refresh it.

  2. Step 2. Paste here

    Paste with Command+V (Mac) or Ctrl+V (Windows). Pasting saves it to the extension right away. There is no button to click.

    Grok Bot: paste the Webhook URL and the Authorization header together.
    Claude: paste the API token, then the Fire URL. One at a time is fine.
    If Chrome asks to allow a site, choose Allow.

This page stays in your browser. Pasting saves into the extension on this computer and nowhere else. ChatGPT and Codex need none of this.
