Send to Grok Bot

Check a destination to list it when you click a post. The menu sends to the one you pick.

Clicking Send on a post reads that post and, on its own page, the author's thread and the post it replies to. That includes the text, link, author, quoted post, links, and media addresses the page already shows. It is sent only to the destination you pick. Keys and tokens stay on this device and are sent only to sign in to that destination. No analytics. Nothing is sold. Click Save to store these settings on this device.

Privacy policy

Paste the one code you were given, then click Connect. It fills in that destination and saves it on this computer. Another code later adds another destination. Paste the code only here, not into a chat.
