Setup

Claude

Three short steps on claude.ai. After that, every post you send runs as a Claude task in the background.

Before you start: add the extension to Chrome, then open its settings and check Send to Claude. You need a paid Claude plan (Pro, Max, Team, or Enterprise).

  1. Create the task

    1. Go to claude.ai and click Routines in the left sidebar.
    2. Create a task and name it Send to Claude.
    3. In the extension settings, click Copy task prompt, then paste it into the task.
    Can't find the extension's button?

    This is the same prompt. Copy it here instead.

    Open the extension settings and click Copy task prompt.

  2. Connect the task to the extension

    1. On the task page, click the three dots next to the Active toggle, then click Edit.
    2. Set Trigger to API.
    3. Copy the Fire URL and the Token.
    4. Paste both into the extension, under Send to Claude, in any order. Click Save. If Chrome asks to allow api.anthropic.com, choose Allow.

  3. Let the task read posts

    1. Send one test post from x.com with Send to Claude.
    2. Back on the task page, open that run from History.
    3. Click the down arrow next to the task name and choose Edit cloud environment.
    4. Set Network access to Custom.
    5. In the extension, click Copy allowed websites, paste the list, and save.

Done. Every post you send shows up under History on the task page, with Claude's reply. Leave the task Active.

Rather skip the setup?

Check Send to Claude in the extension and leave the Fire URL box empty. Clicking a post opens Claude in a new tab with the post filled in. You press Send.
